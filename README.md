# HTML + Tailwind CSS + React + TypeScript

Минимальное приложение на Vite. Код страницы: `src/App.tsx`.
На странице есть шапка и подвал; основное содержимое пока пустое.
Все команды выполняются из папки проекта.

- `index.html` — HTML-страница и контейнер React.
- `src/main.tsx` — точка входа React.
- `src/App.tsx` — компонент приложения на TypeScript.
- `src/components/Header.tsx` и `Footer.tsx` — шапка и подвал страницы.
- `src/styles.css` — импорт Tailwind CSS.

Tailwind подключён через официальный плагин Vite. Используйте его классы
в `className` компонентов, например `<h1 className="text-3xl font-bold">Привет!</h1>`.

Отдельный [справочник Tailwind CSS](docs/TAILWIND.md): классы, назначение,
примеры JSX, адаптивность, состояния и анимации.

[Практические приёмы HTML/CSS](docs/HTML-CSS-PATTERNS.md): типичные задачи
в production-разработке, решения на обычном CSS и аналоги на Tailwind.

## Установка и запуск на Mac

Нужен Node.js 22.12+ или 24+.

```sh
cd /Users/bronylong/personal_website
npm ci
npm run dev
```

Откройте http://127.0.0.1:5173. Для остановки сервера нажмите Ctrl+C.
Установленные зависимости уже есть; `npm ci` нужен после скачивания проекта
или при переустановке зависимостей.

## Просмотр с другого компьютера

Подключите Mac и другой компьютер к одной локальной сети (Wi-Fi или Ethernet).
Если сервер уже запущен, остановите его через Ctrl+C. На Mac выполните:

```sh
npm run dev
```

Vite выведет адрес `Network`, например `http://192.168.1.25:5173/`.
Откройте этот адрес в браузере другого компьютера. На нём достаточно браузера.
Mac и сервер должны оставаться включёнными. Сохранённые изменения кода
автоматически обновляют страницу.

Локальный IP Mac также можно найти в системных настройках сети или командой
`ipconfig getifaddr en0` (если Wi-Fi использует интерфейс `en0`).

Если подключение не работает, проверьте адрес `Network`, одну сеть на обоих
устройствах и разрешение входящих соединений для Node.js в брандмауэре Mac.
Гостевая Wi-Fi-сеть может запрещать соединения между устройствами.

`127.0.0.1` и `localhost` на другом компьютере указывают на сам этот компьютер.
Этот способ рассчитан на локальную сеть; для просмотра через интернет нужно
разместить сборку на хостинге.

## Проверка и сборка

```sh
npm run typecheck
npm run build
npm run preview
```

`build` проверяет TypeScript и создаёт `dist/`. `preview` запускает просмотр
сборки на http://127.0.0.1:4173. `dist/` и `node_modules/` генерируются и
не хранятся в Git.
